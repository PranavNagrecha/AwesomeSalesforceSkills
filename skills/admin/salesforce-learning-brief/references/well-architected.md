# Well-Architected Mapping

| Pillar | Learning-brief behavior |
|---|---|
| Trusted | Preserve source, security, permission, authority, and uncertainty boundaries |
| Easy | Adapt concept order, vocabulary, examples, and practice to the learner's role and level |
| Adaptable | Separate stable mental models from release-sensitive procedures so briefs can be refreshed safely |

The frontmatter's three `well-architected-pillars` (Reliability, User Experience, Operational Excellence) are internal repository mappings, not the Trusted / Easy / Adaptable framing above. (Corrected 2026-10-21: an earlier version said "six dimensions"; the frontmatter lists three.)
