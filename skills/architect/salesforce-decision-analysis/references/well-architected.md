# Well-Architected Mapping

Use Salesforce Well-Architected as a source of evaluation concerns, not as a pre-filled weight model.

| Salesforce Well-Architected pillar | Decision concerns |
|---|---|
| Trusted | Security, privacy, compliance, reliability, explainability, least privilege, failure containment |
| Easy | User effort, operator effort, maintainability, observability, accessibility, adoption |
| Adaptable | Scale, performance, modularity, deployment, extensibility, interoperability, reversibility |

The repository frontmatter uses six internal dimensions—Security, Reliability, Performance, Scalability, User Experience, and Operational Excellence—to make those concerns measurable. Do not present those six dimensions as six official Salesforce pillars.
