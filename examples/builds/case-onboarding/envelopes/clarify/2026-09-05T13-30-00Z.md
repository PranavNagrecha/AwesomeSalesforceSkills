## How to answer, and what happens next

1. Answer in `.sfskills/builds/case-onboarding/CLARIFICATIONS.md` on each `Answer:` line. Copy the proposed default onto the line to accept it; write `DEFER: <reason>` to defer a blocking question. Answers may run several lines.
2. `python3 scripts/build_plan.py ingest-answers .sfskills/builds/case-onboarding/plan.json` (add `--allow-deferred` if any blocking question is deferred).
3. `python3 scripts/build_plan.py gate .sfskills/builds/case-onboarding/plan.json clarifications approve --by "<name>" --notes "<what was decided>"` — a human action; this agent never runs it.
4. Then `/plan-build` against the same build directory.
