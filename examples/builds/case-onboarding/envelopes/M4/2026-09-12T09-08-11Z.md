## 5. The two HIGH findings

**F-40 — the milestone's own goal is not met.** `plan.json` promises *"a Premier case created at
17:00 London time on a Friday … the first-response clock is running on the **EMEA calendar**, shows
4 business hours remaining, does not tick over the weekend."* Both entitlement processes pin
`<businessHours>US Support</businessHours>` on the process **and** on the milestone, and the
milestone's own value is the most specific source the engine consults — so the EMEA calendar the
M4-S03 flow stamps reaches only the escalation clock. 17:00 Friday London is 12:00 New York; 240
business minutes on US Support expire at 21:00 the same Friday London. All three clauses fail.
O-M4S02-02 records the divergence precisely; **no step reads `milestones[].goal`**, so nobody
compared the two. That comparison is this agent's job.

**F-39 — the merged manifest cannot deploy into a clean org.** `settings/Entitlement.settings-meta.xml`
(`enableEntitlements`) is declared in no step's `outputs[]` anywhere in the plan. O-M4S02-01 named
it at M4-S02's scope; the dependency is wider — **three of five steps** need it, because the flow
names `$Record.EntitlementId` and the `Entitlement` object and the Apex names `CaseMilestone` and
`SlaProcess`. Mock deploy run 4's 55/55 does not clear it: `sfskills-dev` already has the feature on.

## 6. The pattern worth naming

**Six of the ten findings are not new facts.** Every component fact was already recorded, accurately,
by a builder or the doc keeper — in two different files, with nothing reading both:

| Finding | File A | File B |

| F-44 | M4-S04 `deploy-order.md` **U3** asks whether the Tier 2 queue has a mailbox | `M2-S04/queues/Tier_2_Engineering.queue-meta.xml` answers it: no `<email>` |
| F-45 | O-M4S03-02 names the active-flow/Apex-test coupling | D-M4S05-04 names the test's org prerequisites |
| F-40 | `plan.json` states M4's goal | O-M4S02-02 states why it cannot be met |
| F-39 | O-M4S02-01 says no step owns the setting | the flow and the Apex both need the feature |
| F-41 | CWB-OBJ-009 asserts the tier→process binding | M4-S02 § 5 says `EntitlementTemplate` is "not in this phase" |
| F-46 | CWB-AUT-026 records the run-time direction | M4-S04 **U2** asks what happens when the field is null |

That is precisely the gap this agent exists to fill. The volume of it in one milestone suggests a
cheap convention for the step-level agents: **when recording an UNVERIFIED item, name the file you
expect the other half to be answered in.**
