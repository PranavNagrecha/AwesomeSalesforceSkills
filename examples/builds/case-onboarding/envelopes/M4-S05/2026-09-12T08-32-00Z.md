## 3. The factory was copied, not adapted — and where the missing behaviour went

The test needs `createAccounts(Integer, Map<String, Object>)` and
`createCases(Integer, Id, Map<String, Object>)`. The template already defines both with exactly
those signatures, so **no method and no behaviour was added to the factory**, and the shared
template was not edited.

The one thing this build's Cases need beyond the factory's defaults is `Origin` and `Priority`
that survive M3-S01's two active validation rules — the factory ships `Origin = 'Email'`, which
is not one of the three values this build's `CaseOrigin` standard value set defines, and sets no
`Priority`. That is supplied **in the test**, through the factory's own `overrides` map, in
`CaseMilestoneServiceTest.caseOverrides(Id)` → `Origin = 'Web'`, `Priority = 'Medium'`. The line
is deliberate: the factory's defaults are shared with every future consumer, and this build's
validation rules are not.
