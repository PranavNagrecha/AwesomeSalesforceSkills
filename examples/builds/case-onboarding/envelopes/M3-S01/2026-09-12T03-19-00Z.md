## The two rules

`Priority_Required_On_Agent_Save` — fires when `Priority` is blank and the saver does not hold
the bypass; error on `Priority`; `active=true`.

```
AND(
  NOT($Permission.Bypass_Case_Intake_Validation),
  ISBLANK(TEXT(Priority))
)
```

`Origin_Must_Be_Known` — fires when `Origin` is blank or is not one of the three `CaseOrigin`
values, and the saver does not hold the bypass; error on `Origin`; `active=true`.

```
AND(
  NOT($Permission.Bypass_Case_Intake_Validation),
  OR(
    ISBLANK(TEXT(Origin)),
    NOT(
      OR(
        ISPICKVAL(Origin, "Email-Support"),
        ISPICKVAL(Origin, "Email-Billing"),
        ISPICKVAL(Origin, "Web")
      )
    )
  )
)
```

`errorMessage` is 218 characters on each rule (cap 255); `description` is 188 and 185 (no
documented cap for this type — see deploy-order.md item 3). Clause order is bypass first, then
the business condition, per the skill's own "Bypass clause is first inside the `AND`".
