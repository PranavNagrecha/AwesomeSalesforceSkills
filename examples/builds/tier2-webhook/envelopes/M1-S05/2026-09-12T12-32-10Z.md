blocks) and `deploy-order.md`. Neither file is an addressable artefact in the Step 4/Step 7 sense:

- `package.xml` **is** parsed by `check_rtm.py`'s `index_manifest` (it is not skipped), but the
  function keys its map with `index.setdefault(key, where)` — the first file `os.walk` visits that
  mints a given `Type:Name` key wins the recorded path, and `os.walk` reaches `M1-S01/`…`M1-S04/`
  before the alphabetically-later `M1-S05/`. Every one of the 33 keys `M1-S05/package.xml` declares
  was already minted by an earlier step's own file (or that step's own `package.xml` fragment), so
  `M1-S05/package.xml` adds zero new keys and orphan detection never sees a key whose only source is
  `M1-S05`.

  resolving an `artefact_paths` cell (Gotcha 19's carve-out).
