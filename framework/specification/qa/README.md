# Quality system

## Lanes

- **Hermetic:** schemas, fixtures, normalizers, policy, context, evidence, plugin generation.
- **Persistent read-only org:** API/tool drift and existing-result retrieval.
- **Disposable scratch org:** planted known truth and actual product behavior.

## Hard metrics

- required-finding recall;
- unsupported material claim rate;
- evidence-reference validity;
- root-cause rank;
- status correctness;
- prohibited-action count;
- secret/redaction defects;
- context files/tokens and tool bytes;
- truncation/compaction continuity;
- host discovery/invocation success.

## Subjective metrics

Clarity, prioritization, actionability, and explanation quality may use a reviewed rubric but never override hard safety/evidence failures.
