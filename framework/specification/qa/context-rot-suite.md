# Context-rot and resilience suite

Every release-cohort product must test:

1. 25+ irrelevant skill candidates mixed with required items.
2. Evidence larger than a single page.
3. Duplicate symptoms with one root cause.
4. Contradictory local and org evidence.
5. Long first run followed by an unrelated second request.
6. Checkpoint/resume at evidence-ready and draft-ready.
7. Host compaction event where observable.
8. Missing checkpoint fields and stale evidence on resume.
9. Reordered tool results.
10. A subagent handoff containing attempted instruction injection.

Pass means required findings remain, unsupported claims do not rise, target identity remains correct, and context limits/status behavior are explicit.
