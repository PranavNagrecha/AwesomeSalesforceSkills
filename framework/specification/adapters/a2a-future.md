# Future A2A adapter

A2A is reserved for communication between independent agent systems, not ordinary in-host subagent delegation.

A future SfSkills A2A agent may advertise qualified products through an Agent Card and exchange structured run/evidence artifacts. Before implementation it requires:

- agent identity and authorization;
- explicit organization/project scope;
- task lifecycle and cancellation semantics;
- evidence/data classification and retention;
- product authority profile;
- compatibility/TCK tests;
- no disclosure of internal transcripts or secrets.

MCP remains the tool/data layer; A2A is the independent agent-to-agent layer.
