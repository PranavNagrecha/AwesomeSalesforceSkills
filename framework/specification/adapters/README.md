# Host adapters

Canonical product behavior lives in framework definitions and schemas. Adapters translate to host-native skills, agents, commands, MCP configuration, hooks, UI, and run storage.

Adapter conformance requires:

1. deterministic generation and drift check;
2. capability report;
3. actual host discovery/invocation smoke test;
4. safety and evidence-path proof;
5. documented local/cloud differences;
6. no semantic fork from the product contract.
