# Agentforce Vibes adapter

Vibes is an org-aware Salesforce host and can use official Salesforce tooling. The SfSkills adapter contributes:

- bounded product/domain knowledge;
- evidence and context contracts;
- read-only product broker policy;
- deployment/test/access/Agentforce quality products;
- replayable outputs and benchmark scenarios.

Do not duplicate editor or official DX capabilities. Map Vibes project/org identity into the run contract, verify target identity, and distinguish Vibes host guarantees from local Cursor/Claude hooks.
