# VS Code and GitHub Copilot adapter

Use portable Agent Skills, custom agents/handoffs, MCP, prompt/command surfaces, and workspace configuration. Treat experimental forked context or host features as negotiated capabilities.

The adapter must not depend on Cursor-only hooks. Safety should primarily come from the restricted evidence broker and read-only product tool surface. Host-native custom agents may improve UX, but claims/evidence/run objects remain portable.
