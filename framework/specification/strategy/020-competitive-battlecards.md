# Competitive battlecards

These are positioning guides, not claims that SfSkills is globally superior. Each claim must be validated against current product versions and a comparable workflow.

## Versus vanilla Cursor / Claude / Copilot

**They win at:** general codebase navigation, code generation, UI, model choice, broad ecosystem, and host execution.

**SfSkills must win at:** Salesforce-specific task routing, explicit org/project identity, platform anti-pattern knowledge, normalized evidence, context budgets, unsupported-claim detection, independent review, known-truth scenarios, and replay.

**Proof required:** same model/host, same evidence, same task; compare time to useful diagnosis, required finding recall, unsupported claims, evidence validity, context cost, and harmful actions.

## Versus official Salesforce DX MCP and Headless 360

**They win at:** official coverage, API/tool authority, native Salesforce evolution, and breadth of operations.

**SfSkills must win at:** least-privilege diagnostic policy, stable cross-tool evidence contracts, product-specific synthesis, host portability, independent quality review, and transparent benchmarks.

**Integration posture:** use official tools upstream; never duplicate broad CRUD/deploy capability. Restrict to explicit read operations in product mode.

## Versus Gearset

**Gearset wins at:** mature org intelligence, deterministic metadata/dependency analysis, compare/deploy, pipelines, observability, automated testing, support, and enterprise adoption.

**SfSkills can win at:** local/portable use across agentic hosts, open run/evidence formats, low-friction diagnostic products, independent model-output QA, and compatibility with multiple upstream tools.

**Do not say:** “replace Gearset.”

**Say:** “Make your coding agent trustworthy around Salesforce evidence, including evidence exported or retrieved from your existing DevOps platform.”

## Versus Copado Agentia

**Copado wins at:** governed end-to-end Salesforce delivery, coordinated lifecycle agents, testing, orchestration, pipelines, and enterprise control.

**SfSkills can win at:** vendor-neutral assurance, read-only local adoption, explicit evidence/claim export, host portability, and independent comparison of agent behavior.

**Do not say:** “full agentic DevOps.”

**Say:** “Add a portable Salesforce reasoning and QA layer before adopting or alongside lifecycle automation.”

## Versus Elements.cloud / Salto / metadata intelligence

**They win at:** deep metadata/configuration models, dependency graphs, impact analysis, documentation, and configuration workflows.

**SfSkills can win at:** composing local source, live read-only observations, captured jobs, governed skills, and vendor evidence into one reviewed diagnosis; running inside the practitioner’s host; measuring context and output quality.

**Integration opportunity:** ingest signed/exported dependency evidence and preserve vendor provenance.

## Versus prompt and skill libraries

**They win at:** simplicity and content breadth.

**SfSkills must win at:** installability, typed products, read-only evidence, bounded context, independent review, replay, host tests, and real-org known truth.

## Versus internal consulting playbooks

**They win at:** customer-specific knowledge and senior expertise.

**SfSkills can win at:** consistency, onboarding, replay, cross-client isolation, evidence discipline, measurable quality, and turning incidents into regression scenarios.

**Integration opportunity:** private team overlays and scenario packs without uploading customer data to a public corpus.
