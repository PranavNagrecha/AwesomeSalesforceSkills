# Category and positioning

## Category name

**Salesforce AI Engineering Framework**

## Product brand

**SfSkills**

## One-sentence position

SfSkills is the portable Salesforce engineering intelligence and assurance layer that gives coding agents bounded domain context, read-only org and project evidence, independently reviewed diagnoses, and replayable quality proof.

## What it replaces

Initially, it replaces fragmented manual investigation around failed deployments, Apex tests, access, change impact, automation behavior, release risk, and agent quality. It also replaces ad hoc Salesforce prompt packs that cannot prove which context or evidence produced an answer.

## What it does not replace

It does not initially replace:

- Salesforce as the system of record or official tool provider;
- Cursor, Claude, Copilot, or Vibes as the host/model UX;
- Gearset, Copado, Flosum, DevOps Center, Salto, or other release platforms;
- Elements or similar deep org graph products;
- Provar or broader testing platforms;
- source control, CI, issue tracking, observability, or enterprise governance.

It connects to and improves reasoning around those systems.

## Why the category exists

The market is converging from both directions:

1. Salesforce exposes broad MCP, skills, and agent-development capabilities.
2. Agentic IDEs package skills, subagents, commands, MCP, hooks, and cloud execution.
3. DevOps and org-intelligence vendors increasingly add org-grounded AI agents.

Raw tool access and generic code generation are therefore becoming commodities. The missing category is a portable discipline layer that answers:

- What evidence did the agent use?
- Was it the correct org/project/job?
- What context was loaded and what was omitted?
- Which material claims are unsupported or contradicted?
- Did the host actually enforce safety?
- Does the product succeed on known Salesforce truth?
- Can the run be replayed after the model or host changes?

## Positioning formula

For Salesforce developers, admins, architects, release engineers, consultants, and Agentforce builders who use agentic development tools, SfSkills provides evidence-grounded engineering diagnosis and assurance across hosts. Unlike a generic coding agent or static prompt library, it combines a governed Salesforce knowledge corpus with read-only target evidence, context budgets, claim/evidence validation, independent review, and real-org behavioral QA.

## Category proof

The category is credible only when the product demonstrates:

- faster useful diagnosis than raw logs or vanilla host;
- high required-finding recall on versioned scenarios;
- materially lower unsupported-claim rate;
- valid, resolvable evidence references;
- zero prohibited Salesforce mutations;
- correct partial/refused behavior;
- repeat use by real practitioners.
