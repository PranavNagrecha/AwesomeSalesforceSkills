# Competitive landscape

## Comparison categories

| Category | Representative products | Established strengths | SfSkills opening |
|---|---|---|---|
| Salesforce official AI/developer platform | Agentforce Vibes, Salesforce DX MCP, Headless 360, Agentforce Builder | Official APIs, org-aware operations, broad skills/tools, current metadata and testing | Cross-host products, strict diagnostic authority, claim/evidence review, replay, open benchmark |
| Salesforce DevOps | Gearset, Copado, Flosum, DevOps Center | Pipelines, compare/deploy, governance, testing, observability, delivery orchestration | Portable diagnosis and assurance around raw/pipeline evidence; model-output QA |
| Org/change intelligence | Gearset Org Intelligence, Elements.cloud, Salto, Metazoa | Metadata graphs, dependencies, impact, drift, documentation, technical debt | Compose vendor/local/org/job evidence into reviewed host-native products; portable run format |
| Salesforce testing | Salesforce testing, Provar, Copado, Gearset | Test creation/execution, regression, UI/API automation, release gates | Failure-root-cause reasoning, evidence-linked explanation, agent-quality benchmark |
| Agentic IDEs | Cursor, Claude Code, Copilot, Vibes | Models, coding UX, codebase search, tools, cloud execution | Salesforce product contracts, knowledge governance, least privilege, known-truth QA |
| Prompt/skill libraries | community repositories | Breadth, reuse, low barrier | Installation, typed jobs, target evidence, context budgets, independent review, behavioral proof |

## Incumbent reality

Gearset explicitly combines deterministic org/dependency analysis with AI, testing, observability, and delivery. Copado Agentia embeds coordinated agents throughout a governed lifecycle. Elements.cloud and Salto provide deep change/dependency intelligence. Salesforce itself is reducing tool-surface/context problems through skills and compact discovery patterns.

SfSkills therefore cannot win by claiming “Salesforce AI,” “org intelligence,” or “agentic DevOps” in the abstract. Those markets already contain mature products with data, workflows, support, and distribution.

## Positioning

SfSkills should position itself as **the Salesforce engineering intelligence and assurance layer for agentic development**.

The initial promise is:

> Make any supported coding agent materially better at understanding Salesforce failures, access, impact, architecture, and agent quality—and show the evidence, context, safety, and benchmark behind the answer.

## Competitive test

Every flagship product is compared against:

1. the same host/model with raw evidence and no SfSkills;
2. selected SfSkills knowledge without the full framework where practical;
3. the full framework;
4. a human-reviewed known-truth rubric;
5. an incumbent workflow only where inputs and outcomes are comparable.

SfSkills wins only when it improves required-finding recall, evidence validity, time to useful diagnosis, safe status/recommendations, context efficiency, or sustained use. A longer report is not a win.
