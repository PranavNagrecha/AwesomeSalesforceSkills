# Personas and jobs to be done

## Developer

Needs root-cause diagnosis across Apex, LWC, SOQL, tests, metadata, and deployment state. Values source mapping, stack traces, reliable platform constraints, and executable verification.

## Admin / declarative builder

Needs Flow, permissions, data model, page, routing, and automation explanations without code-first assumptions. Values exact Setup concepts, side effects, and safe validation.

## Architect / technical lead

Needs impact, trust, maintainability, dependency, release, and trade-off analysis. Values evidence lineage, contradictions, decision records, and prioritization.

## Release / DevOps engineer

Needs failure clustering, readiness, environment drift, test signal, and safe remediation ordering. Values speed, repeatability, and integration with existing pipeline evidence.

## Consultant / system integrator

Needs consistent cross-client discovery and deliverables while preventing org/project mix-ups. Values explicit target identity, standalone mode, redaction, and replayable packets.

## Security / compliance reviewer

Needs least privilege, access paths, sensitive data boundaries, auditability, and no hidden mutation. Values deterministic policy and evidence provenance.

## Agentforce builder

Needs topic/action/guardrail/test quality, metadata and action implementation analysis, and release readiness. Values native Agentforce concepts and current release knowledge.

## Maintainer / contributor

Needs schema-valid contributions, current official sources, deterministic tests, behavioral fixtures, and confidence that generated adapters remain in sync.

## Common cross-persona jobs

- Diagnose a blocked delivery event.
- Explain access or behavior using actual evidence.
- Predict change impact before implementation.
- Review a design or release for platform-specific risk.
- Convert an incident into a reusable regression scenario.
- Preserve reasoning quality across hosts and long conversations.
