I can't confirm a fourth value. The three I know of for `runInMode` on `Flow` are:

- **DefaultMode**: the flow runs in the context of how it was launched. Record-triggered flows run in system context, and screen flows run in user context.
- **SystemModeWithSharing**: the flow runs in system mode but enforces sharing rules for the running user.
- **SystemModeWithoutSharing**: the flow runs in system mode and ignores sharing rules.

API 68.0 corresponds to Winter '27, which is after my knowledge cutoff (June 2026). A new enum value could have been added in that release without my knowing.
