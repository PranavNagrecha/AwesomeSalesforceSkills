**Effectively yes, unless you have a backup of that tenant secret.**

**What happens when you destroy a secret**
- Shield derives data encryption keys from the tenant secret plus a Salesforce-held master secret. Destroying the tenant secret permanently deletes the customer-side key material.
- Any data still encrypted with that secret can no longer be decrypted. That includes field values, files and attachments, and any Salesforce backups that contain them.
- Salesforce Support can't recover it. The key material is gone.
- Only an archived secret can be destroyed, not the active one. By then new writes already use the newer secret, so the loss covers only data that was never re-encrypted.

**Ways to recover**
1. **Exported backup:** If you exported the tenant secret before destroying it, you can re-import it and the data becomes readable again. You can't export a secret after it's destroyed, so this has to happen beforehand. Store the export securely.
2. **BYOK:** If you uploaded your own tenant secret material (customer-supplied key material wrapped with your certificate), you can re-upload the same material, since you hold the original.
3. **Cache-Only Key Service:** The key lives in your external key service, so you can restore it from there if you still have it.

**Prevention before you destroy anything**
- Re-encrypt existing data with the active secret first. Use the "Synchronize" / key rotation option for fields, and the equivalent for files.
- Check the Encryption Statistics page, or query the data, to confirm nothing is still encrypted with the old key version.
- Export and back up the secret before destroying it anyway.
- Test in a sandbox first. Sandbox refreshes don't carry over your production tenant secrets, so don't assume a sandbox test proves the same state as production.

If you've already destroyed one and have no export or BYOK material, treat the data encrypted with that secret as permanently unreadable. Restore from an external source such as a data warehouse, an unencrypted export, or an integration source of truth.
